# Flipkart Review Sentiment Analysis

## Overview
This project analyzes customer reviews of the iPhone 15 (128GB) scraped from Flipkart.
Sentiment analysis is performed using TextBlob to classify reviews as positive or negative.

## Tools & Libraries
- Python
- Selenium
- BeautifulSoup
- Pandas
- TextBlob
- Matplotlib
- Seaborn
- WordCloud

## Steps Performed
1. Web scraping of reviews
2. Data cleaning and preprocessing
3. Sentiment analysis
4. Data visualization
5. Insights and recommendations
